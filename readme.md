# G2D Website

Página institucional da G2D — comunidade de aceleração de carreira.

Site estático (HTML + CSS), responsivo: layout mobile (390px) e desktop (1440px).

## Rodar localmente

```bash
python3 -m http.server 8000
# abra http://localhost:8000
```

## Deploy

Hospedado na Vercel como site estático: nenhum build é necessário.
Importe o repositório em https://vercel.com/new, mantenha o framework
como "Other" e faça deploy. Cada push na branch principal gera um novo deploy.
